# Sportpro-

## בוט מסחר לחשבון דמו (`tradingbot/`)

בוט שבודק אסטרטגיות מסחר על 26 שנות נתונים אמיתיים, ואחר כך סוחר **בחשבון דמו** (כסף וירטואלי) ב־Alpaca.
המטרה: לראות בעיניים מה בוט מסחר באמת מסוגל לעשות — בלי הבטחות ובלי צילומי מסך נבחרים.

### מה הוא עושה
- **נתונים:** מחירים יומיים מ־Yahoo Finance, מתואמים לספליטים ודיבידנדים.
- **6 אסטרטגיות:**
  | שם | רעיון |
  |---|---|
  | `buy_hold` | קונים ומחזיקים — קו הבסיס שכל בוט צריך לנצח |
  | `trend` | מחזיקים רק כשהמחיר מעל ממוצע 200 יום וממוצע 50 מעל ממוצע 200 |
  | `momentum` | מחזיקים רק כשהתשואה ב־12 החודשים האחרונים חיובית |
  | `rsi2` | קונים ירידות חדות קצרות בתוך מגמת עלייה, מוכרים בתיקון |
  | `trend_voltarget` | `trend` + הקטנת הפוזיציה כשהשוק תנודתי |
  | `combo` | ממוצע של שלוש האסטרטגיות + התאמה לתנודתיות (ברירת המחדל) |
- **בקטסט הוגן:** ההחלטה מתקבלת בסגירה ומבוצעת **בפתיחה של היום הבא** (אין הצצה לעתיד — יש על זה בדיקות), עם עמלה+החלקה של 5 נקודות בסיס לכל צד.
- **בדיקה מחוץ למדגם:** 70% הראשונים של ההיסטוריה ל"פיתוח", 30% האחרונים (בערך 2018–2026) נשמרים לבדיקה נקייה.

### התוצאות (תיק שווה משקל: SPY, QQQ, IWM, EFA, TLT, GLD)

| אסטרטגיה | תשואה שנתית (מחוץ למדגם) | ירידה מקסימלית | Sharpe |
|---|---|---|---|
| buy_hold | 12.2% | ‎-26.0% | 0.84 |
| trend | 8.7% | ‎-10.7% | 0.98 |
| trend_voltarget | 6.6% | ‎-9.2% | 0.90 |
| combo | 5.1% | ‎-8.1% | 0.91 |

**מה זה אומר, בכנות:**
- אף אסטרטגיה **לא** הרוויחה יותר מקנייה והחזקה פשוטה בשנים האחרונות.
- מה שהבוט כן נותן: **ירידות קטנות בהרבה** (‎-8% עד ‎-11% במקום ‎-26%) ותשואה יציבה יותר ביחס לסיכון.
- בנכסים בודדים יש שנים גרועות — למשל על IWM ו־TLT רוב האסטרטגיות הפסידו או כמעט לא הרוויחו.
- הבקטסט מניח שמזומן לא מרוויח ריבית, כך שבפועל האסטרטגיות שיוצאות למזומן היו מרוויחות קצת יותר.
- **ביצועי עבר אינם מבטיחים ביצועים עתידיים.** "6,700 ש"ח ביום" זה לא משהו שבוט אמיתי עושה.

### הרצה

```bash
pip install -r requirements.txt

# בקטסט על כל האסטרטגיות
python -m tradingbot backtest

# נכסים/אסטרטגיות/עמלות אחרים
python -m tradingbot backtest --symbols SPY QQQ --strategies trend combo --cost 10

# בדיקות
python -m pytest -q
```

### מסחר בחשבון דמו (Alpaca Paper Trading)
1. נרשמים בחינם ב־https://alpaca.markets ונכנסים ל־**Paper Trading** (מקבלים $100,000 וירטואליים).
2. יוצרים API Keys של חשבון ה־Paper.
3. מריצים **פעם ביום, אחרי סגירת המסחר בארה"ב** (23:00 שעון ישראל):

```bash
export ALPACA_API_KEY=...
export ALPACA_SECRET_KEY=...

python -m tradingbot paper            # הרצה יבשה: מראה מה היה קונה/מוכר
python -m tradingbot paper --submit   # שולח פקודות לחשבון הדמו
```

כל הרצה נרשמת ב־`paper_log.csv`. הבוט מתחבר **רק** לכתובת ה־paper של Alpaca — הוא לא יכול לסחור בכסף אמיתי.
